## Fitur
* **Role:** HRD Manajer
* **Task a:** Memilih tanggal, bulan, tahun untuk melihat pengajuan cuti sesuai periode.
* **Task b:** Menampilkan nama pegawai, periode cuti yang diajukan, dan durasi cuti.
* **Task c:** Memilih nama pegawai untuk menampilkan riwayat cuti dan sisa cuti tahun berjalan.

## Menjalankan Sistem
```bash
npm install
npm test      # Menjalankan unit tests
npm start     # Menjalankan server pada port 3001
```
Buka antarmuka UI di browser: **http://localhost:3001**
